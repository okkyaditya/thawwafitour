# Asset & Gambar Thawwafi Tour

Direktori ini berisi seluruh aset gambar statis yang digunakan di website Thawwafi Tour. Anda dapat dengan mudah mengganti atau menambahkan gambar baru sesuai kebutuhan:

## Struktur Folder:
- `/public/img/kaaba-hero.jpg` — Gambar latar belakang utama untuk Hero Banner (Ka'bah / Masjidil Haram).
- `/public/img/hero/` — Tempat untuk gambar hero banner tambahan atau alternatif.
- `/public/img/partners/` — Tempat untuk logo partner resmi (format SVG atau PNG transparan).
- `/public/img/packages/` — Tempat untuk foto paket / hotel / ziarah.
- `/public/img/blog/` — Tempat untuk gambar cover artikel blog.

## Tips Penggantian Gambar:
1. **Ukuran Hero:** Disarankan resolusi minimal `1920x1080` (JPG/WebP terkompresi).
2. **Logo Partner:** Disarankan format SVG atau PNG transparan dengan aspect ratio horizontal/square yang konsisten.
3. **Card Image:** Disarankan aspect ratio `16:9` atau `4:3`.
